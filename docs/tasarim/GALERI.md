# Kronikler — ilk uyarlama / reddedilen tasarım

> Kullanıcı bu uyarlamayı onaylamadı. NPC yüz/gövde montajı ve mockup benzerliği
> yetersiz bulundu. Aşağıdaki galeri ilk denemedir; tamamlanmış tasarım değildir.
> NPC montajı uygulamadan kaldırıldı; ana ekran/NPC/şehir yeniden çalışılıyor.

42 sayfa, onaylanan [ilk görsel taslağın](ekran-taslaklari-v1.png) koyu parşömen,
pirinç çerçeve ve sıcak Anadolu sahneleriyle uygulandı. Aşağıdaki görseller **gerçek
sayfa bileşenlerinin tarayıcı önizlemeleridir**; Android/APK ekran görüntüsü değildir.
Her görsel örnek kayıtla sayfanın ilk görünümünü gösterir; aşağı kaydırılan bütün
panellerin veya bütün oyun durumlarının bitmiş testi anlamına gelmez.

Görsele dokunarak büyük açabilirsin. Başlık, içerik ve işlemler resmin üstüne çizilmiş
sahte düğmeler değildir: uygulamadaki yerel bileşenlerdir. Oyun verisi/şartları korunur.
Çok oyunculu örnekler görsel kayıt kullanır; canlı sunucu testi yapılmadı.

## Her sayfanın düzeni

| Rota | Tasarım ve bilgi sırası |
|---|---|
| `/` | Kapak resmi, devam/yeni oyun, çevrimdışı ve diyar girişleri. |
| `/yeni-oyun` | Kapak içinde ad, cinsiyet, tabiat ve soy formu; mevcut kayıt uyarısı korunur. |
| `/oyun` | Mevsim sahnesi → kişi/dört gösterge → aylık karar → acil uyarılar → son üç gelişme → yaşam defteri → çalışma/uğraşlar. |
| `/oyun/karakter` | Kişi sahnesi → gerçek portre/arma → sağlık/usta → katmanlı beceri, teçhizat ve çanta. |
| `/oyun/sehir` | Çarşı panoraması → güncel güvenlik/refah/tanınma → iki sütun mekânlar → ambar/yardım → yerel ekonomi. |
| `/oyun/npc/[id]` | Meslek ortamı + duruş + kalıcı yaş yüzü → gerçek kimlik/ruh hâli → katlanır çevre → konuşma/işlemler. |
| `/oyun/atolye` | Atölye sahnesi → tarif ailesi → malzeme/ustalık kapısı → üretim düğmesi. |
| `/oyun/pazar` | Diyar ve piyasa başlığı → tezgâh → açık fiyat/stok/alım → kervan ve sarraf. |
| `/oyun/meslek` | Lonca sahnesi → mevcut kariyer/sınav → meslek seçimi ve kayıp uyarısı. |
| `/oyun/emek` | Kitap sahnesi → tasarım, sanat, ses ve açık kaynak katkıları. |
| `/oyun/mulkler` | Mülk afişi → servet/net gelir/işçi → tapuların işlemleri → gerçek alım tahmini. |
| `/oyun/beceriler` | Medrese sahnesi → toplam gelişim → beceri ve hüner seçimleri. |
| `/oyun/mektep` | Medrese sahnesi → sınav durumu → kalan ders gücü → yaşa uygun dersler/öğretmen; yetişkinde beceri/tefekkür bağlantıları. |
| `/oyun/gorevler` | Lonca sahnesi → açık işler → şart/eylem/yönlendirme satırları. |
| `/oyun/iliskiler` | Yer/kişi sayısı → eşleştirme → önemli kişiler → filtreli sosyal çevre. |
| `/oyun/mahalle` | Ev sahnesi → yerel algı → mekân/ziyaret hakkı → gerçek NPC listesi. |
| `/oyun/sosyal` | Topluluk sahnesi → mevki/itibar/nam → unvan ve yerel sosyal kararlar. |
| `/oyun/copcatan` | Düğün sahnesi → görüşme bedeli → yaş/servet filtreleri → gerçek adaylar. |
| `/oyun/ocak` | Ocak sahnesi → ata kaydı → soy yeteneği → yeni hayat formu. |
| `/oyun/nesil` | Doğum sahnesi → ölümde vâris seçimi / hayatta eğitim → miras ve önizleme. |
| `/oyun/hanedan` | Konak sahnesi → hane mührü → soy/gerçek aile → rakip haneler ve devlet bağlantısı. |
| `/oyun/diplomasi` | Meclis sahnesi → gelen teklifler/ahitler → hükümdar hedefi → şartlar, bedel, yanıt. |
| `/oyun/orgutler` | Lonca sahnesi → bağlılık/liyakat → görev ve üyelik kararları. |
| `/oyun/savas` | Cephe sahnesi → devlet ordusu/katılım/ikmal → kişisel dövüş. Dövüş açılınca mevcut taktik alanı korunur. |
| `/oyun/suc` | Kadı sahnesi → gölge namı → suçun getirisi/riski → yasadışı eylemler. |
| `/oyun/harita` | Yol sahnesi → dokunulabilir beylik haritası → seçili bölge/yerleşimler → seyahat. |
| `/oyun/diyar/[name]` | Yer sahnesi → güncel durum → savaş sonuçları → yönetim ve seyahat şartları. |
| `/oyun/haberler` | Tarih/çarşı sahnesi → yerel haberler → diyar olayları ve söylentiler. |
| `/oyun/tarih` | Defter sahnesi → tam günlük filtreleri → tarihe göre olay kayıtları. |
| `/oyun/kronik` | Defter sahnesi → tamamlanan yaylar/kararlar → dost haneler → kalıcı soy kayıtları. |
| `/oyun/roman` | Konak sahnesi/kişi adı → paylaşılabilir hayat anlatısı → bölüm/hesap dökümü. |
| `/oyun/hikayeler` | Yol sahnesi → ilerleme → açık yaylar → bitmiş anlatılar. |
| `/oyun/divan` | Kadı sahnesi → günün davası → üç değer seçimi → lakaplar/arşiv. |
| `/oyun/basarimlar` | Medrese sahnesi → toplam/yaklaşılan hedefler → gruplu nişaneler. |
| `/oyun/menu` | Pusula/konak sahnesi → geçim, güç, diyar/soy, kayıt rotaları ve durum rozetleri. |
| `/oyun/ayarlar` | Kısa medrese başlığı → yardım/kayıt → dil/ses/titreşim/sade mod → içe/dışa aktarma. |
| `/oyun/sss` | Kısa kitap başlığı → konu grupları → açılır yanıt satırları. |
| `/cok-oyunculu` | Çarşı sahnesi → isim/bağlantı formu → diyar listesi. |
| `/cok-oyunculu/oyun` | Meclis başlığı → canlı oyuncular → taht/beylik/lonca kararları → haberler. |
| `/cok-oyunculu/harita` | Yol sahnesi → taht → beylik kartları ve gerçek sunucu durumları. |
| `/cok-oyunculu/diplomasi` | Kadı sahnesi → şeref/teklifler → oyuncu/NPC hedefi → diplomatik eylemler. |
| `/cok-oyunculu/diyar` | Bağlantı şeridi → diyar/tarih/taht → oyuncular → hazır/sohbet. |

## Yapılan kontroller ve sınırlar

- 42/42 rota; 320 ve 390 × 844; Chromium'da 4× CPU yavaşlatma: JS çalışma hatası,
  yatay taşma ve ölçülen 44 piksel altı düğme hedefi yok.
- 19 ek görünüm: tr/en/es/pt/ar/ru; uzun ad; aylık karar; savaş; hükümdar;
  çocuk; ölüm/vâris; Arapça/Rusça kadın hükümdar; altı görünümde tarayıcı yazısını 1,3× büyütme.
- Aylık karar düğmesine çift dokunma tek sonuç uyguladı; şehir rotası ve yardım
  açılımı hedefli arayüz kontrolünden geçti. Aylık kayıt/risk/fırsat kontrolü temiz.
- TypeScript, altı dil/ikon ve dil karışması, 42 rota envanteri temiz.
- Android için Metro dışa aktarımı başarılı: 2374 modül; bu APK veya Hermes/telefon
  çalıştırma testi değildir. Uzun smoke çalıştırılmadı. Yeni APK üretilmedi.
- Önizleme ses/titreşim/ağ/depolama/Skia'yı taklit eder; animasyon performansı,
  Android yazı büyütmesi, sistem kenarları/klavye ve fiziksel dokunma ayrıca sınanmalı.
